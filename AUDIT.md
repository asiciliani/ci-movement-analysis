# Audit and restructuring — October 2026

A code and methodology audit of the proof-of-concept found that none of the four claims presented
to the thesis director were supported by the code or the data. This file records what was wrong,
what was changed, and what remains open. The old scripts live in git history (commit before
`AUDIT.md` was added).

## Changes
* Two-stage pipeline (`run_tracking.py` → `run_features.py`); raw tracks saved once.
* BoT-SORT + ReID default; tracking diagnostics; camera ego-motion estimation and screening.
* Gap-aware Savitzky-Golay derivatives; no interpolation across gaps; no clipping.
* Body-length (or metric) units for every quantity; noise floor reported per video.
* SPARC/LDLJ on windows as the smoothness measures; Effort = jerk × KE removed.
* Within-video hypothesis tests with sign test, Wilcoxon, Cliff's delta, mixed models, surrogate
  tests for cross-correlation (`analyze_claims.py`).
* Proximity-graph analysis for jams (no neural network; honest name).
* Dataset inclusion rules and per-video exclusion reasons (`aggregate_dataset.py`).
* Curated acquisition with automatic static-camera / two-person screening.
* Removed: fabricated-phase figure scripts, HUD "claim" videos, mock VLM tracker, the zip, names.
* Tests: `tests/test_kinematics.py` (gap handling, noise floor, scale invariance, lag sign, surrogates).
